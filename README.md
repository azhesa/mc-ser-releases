# 浮空境域啟動器

這個公開儲存庫只提供下載與更新資訊，開發原始碼另行保管。

## 玩家下載

[下載 Windows x64 啟動器](https://github.com/azhesa/mc-ser-releases/releases/latest/download/SkyRealm-Windows-x64.zip)

1. 關閉舊版，將 ZIP 完整解壓縮到新資料夾。
2. 執行 `SkyRealm.exe`，保留其他 DLL 與更新助手。
3. 按「登入 Microsoft」，使用擁有 Minecraft Java 版的帳號登入。

目前仍是開發測試版，不含遊戲下載與進服功能。真實帳號登入與玩家電腦上的跨版本更新仍需實測。

## 更新

0.5.1 開始使用這個公開發布庫。開啟時背景檢查，左側「更新」可手動檢查。有新版時顯示更新說明，由玩家確認後下載、校驗並重新啟動。

較舊版本仍指向原本的更新來源，需要手動安裝 0.5.1 一次。

`update.json` 是程式使用的更新清單，玩家不用開啟。GitHub 自動顯示的 `Source code` 只包含發布庫文件，不是啟動器下載包。

[查看版本與更新說明](https://github.com/azhesa/mc-ser-releases/releases)
